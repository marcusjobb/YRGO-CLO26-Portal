Välj hur du kör MongoDB

Du kan köra MongoDB på två sätt. Båda används i kursen.

AlternativNär du väljer detConnection string
DockerDu vill ha en databas på din egen datormongodb://localhost:27017
MongoDB AtlasDu vill nå databasen från flera datorer, eller slipper installera någotmongodb+srv://... från Atlas
NuGet och connection string

Skapa ett konsolprojekt och lägg till drivrutinen:

dotnet new console -n MongoLathund
cd MongoLathund

Kör den här för MongoDB-drivrutinen:

dotnet add package MongoDB.Driver

Kör den här för att läsa konfigurationen (JSON, user secrets och miljövariabler):

dotnet add package Microsoft.Extensions.Configuration.Json
dotnet add package Microsoft.Extensions.Configuration.UserSecrets
dotnet add package Microsoft.Extensions.Configuration.EnvironmentVariables

Connection strings i appsettings.json. Använd platshållare för lösenordet, precis som i EF-lathunden:

{
  "ConnectionStrings": {
    "MongoLocal": "mongodb://localhost:27017",
    "MongoAtlas": "mongodb+srv://<användarnamn>:<lösenord>@<kluster>.mongodb.net/?retryWrites=true&w=majority"
  }
}

Lägg det riktiga Atlas-lösenordet i user secrets, inte i filen:

dotnet user-secrets init
dotnet user-secrets set "ConnectionStrings:MongoAtlas" "mongodb+srv://<användarnamn>:<riktigt lösenord>@<kluster>.mongodb.net/?retryWrites=true&w=majority"

Läs konfigurationen och anslut:

var config = new ConfigurationBuilder()
    .AddJsonFile("appsettings.json")
    .AddUserSecrets<Program>(optional: true)
    .AddEnvironmentVariables()
    .Build();

var connectionString = config.GetConnectionString("MongoLocal");

// Tänk på att lägga till Try Catch där anslutningen kan misslyckas
var client = new MongoClient(connectionString);
var database = client.GetDatabase("webshop");
var products = database.GetCollection<Product>("products");

Byt MongoLocal mot MongoAtlas när du vill ansluta till Atlas. Samma kod fungerar för båda.

Docker

Starta MongoDB-containern:

docker run --name mongo1 -p 27017:27017 -v mongo-data:/data/db -d mongo

Volymen mongo-data gör att datan finns kvar om du tar bort containern. Kontrollera att den kör:

docker ps

Starta om en stoppad container med docker start mongo1.

MongoDB Atlas

1. Registrera dig

Gå till mongodb.com/cloud/atlas och skapa ett konto. Gratisnivån (M0) räcker för kursen.

2. Skapa ett kluster

Välj Build a Database → M0 Free och välj ett område nära dig. Klustret tar några minuter att skapa.

3. Skapa en databasanvändare

Under Security → Database Access klickar du på Add New Database User. Välj användarnamn och ett starkt lösenord. Det är inte ditt kontolösenord.

Spara lösenordet direkt, till exempel i en lösenordshanterare. Atlas visar det inte igen.

4. Hämta connection string

Klicka på Connect på klustret → Drivers → välj C# och kopiera strängen. Byt ut <password> mot ditt lösenord, och lägg det i user secrets (se nedan).

mongodb+srv://<användarnamn>:<lösenord>@<kluster>.mongodb.net/?retryWrites=true&w=majority
IP-adress i Atlas

Atlas släpper bara in anslutningar från IP-adresser som du godkänt. Det är ett skydd. Så här lägger du till din egen adress:

Security → Network Access → Add IP Address → Add Current IP Address → Confirm.

Det är din egen IP-adress. Använd den hemma och på skolan om den inte ändras. Har adressen ändrats, lägg till den nya.

På lektionerna lägger vi till 0.0.0.0/0, som betyder alla adresser. Det förenklar för alla. Ta bort posten efter lektionen, annars kan vem som helst på internet försöka logga in mot klustret. Användaren och lösenordet skyddar fortfarande databasen.

MongoDB Compass

Compass är ett grafiskt verktyg för MongoDB. Ladda ner det från mongodb.com/try/download/compass och installera det.

Öppna Compass och klistra in connection string i fältet URI. Klicka sedan på Connect.

Compass visar databaser, collections och dokument. Du kan också köra frågor och ändra dokument för hand.

CRUD

Modellen är en vanlig C#-klass. MongoDB lagrar den som ett dokument. Id blir _id.

using MongoDB.Bson;

public class Product
{
    public ObjectId Id { get; set; }
    public string Name { get; set; } = "";
    public decimal Price { get; set; }
}

Create

Lägg till ett dokument. _id skapas automatiskt om du inte sätter det.

products.InsertOne(new Product { Name = "Kaffe", Price = 49m });

Read

Hämta med ett filter. Find returnerar en lista när du anropar ToList().

var billiga = products.Find(p => p.Price < 100).ToList();

Update

Ange vilket dokument som ska ändras och vilket fält som ska få nytt värde.

products.UpdateOne(
    p => p.Name == "Kaffe",
    Builders<Product>.Update.Set(p => p.Price, 39m));

Delete

Ta bort det första dokument som matchar filtret.

products.DeleteOne(p => p.Name == "Kaffe");

Till skillnad från EF Core sparar varje operation direkt. Det finns inget SaveChanges().

Transaktioner och replica set

Transaktioner över flera dokument kräver ett replica set. Atlas är redan ett replica set, så där fungerar det direkt. En lokal Docker-container med en enda nod måste startas som ett replica set:

docker run --name mongo-rs -p 27017:27017 -d mongo --replSet rs0
docker exec mongo-rs mongosh --eval "rs.initiate()"

Sedan körs transaktionen i en session:

using var session = client.StartSession();
session.StartTransaction();
try
{
    products.UpdateOne(session, p => p.Name == "Kaffe", Builders<Product>.Update.Inc(p => p.Price, -5m));
    orders.InsertOne(session, new Order { ProductName = "Kaffe" });
    session.CommitTransaction();
}
catch
{
    session.AbortTransaction();
    throw;
}

Varje operation i transaktionen får session som första argument. Glömmer du det körs den utanför transaktionen.

Seeder: startdata

Fyll collectionen med startdata bara om den är tom. Då blir det inga dubbletter när du startar programmet igen:

if (products.CountDocuments(p => true) == 0)
{
    products.InsertMany(new[]
    {
        new Product { Name = "Kaffe", Price = 49m },
        new Product { Name = "Te", Price = 35m }
    });
}

Samma mönster som i EF-lathunden: kontrollera först, skriv sedan.

Koppla på från IDE

För MongoDB är Compass det enklaste verktyget. I VS Code kan du också använda tillägget.

VS Code

Installera tillägget MongoDB for VS Code av MongoDB. Lägg till en anslutning med connection string, och du ser databaserna i sidopanelen.

Visual Studio och Rider

Här finns inget inbyggt MongoDB-verktyg i standardinstallationen. Använd Compass vid sidan av.

Tips och tricks
  • Connection string fungerar inte mot Atlas? Kontrollera först att din IP-adress finns i Network Access.
  • Ingen data syns? Kontrollera databasens namn. Det måste vara samma i koden och i Compass.
  • Lösenord i git: lägg dem i user secrets eller miljövariabler, aldrig i appsettings.json.
  • Lägg inte till 0.0.0.0/0 och glöm bort den. Ta bort posten efter lektionen.
  • Använd _id som nyckel. Sök på det när du vill hämta ett specifikt dokument.
